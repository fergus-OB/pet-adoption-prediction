# Source Code

This folder will contain cleaned R scripts for the pet adoption prediction workflow.

Planned modules:

- `preprocessing.R` — data cleaning, target transformation, and feature engineering
- `exploratory_analysis.R` — EDA plots and distribution checks
- `logistic_regression.R` — baseline and stepwise logistic regression models
- `lasso_model.R` — LASSO regularisation and lambda selection
- `cart_model.R` — CART decision-tree training and tuning
- `model_evaluation.R` — confusion matrices, ROC curves, AUC, and repeated validation

Raw exploratory scripts are being cleaned before inclusion.
