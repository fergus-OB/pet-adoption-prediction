# Outputs

This folder contains selected figures from the pet adoption prediction project.

## Exploratory Analysis

- `Adoption Speed Histogram.png` — distribution of the original five-class adoption speed target
- `binary_AdoptionSpeed Histogram.png` — distribution after converting adoption speed into a binary target
- `Age Histogram.png` — original age distribution, showing strong right skew
- `RealHistogramofLog10Age.png` — log-transformed age distribution
- `Adoption Speed v Log10Age Boxplot.png` — relationship between log-transformed age and adoption speed

## Model Evaluation

- `FindingLambdaForLasso.png` — cross-validation curve for selecting the LASSO regularisation parameter
- `ROC Curve Stepper vs LASSO.png` — ROC comparison between stepwise and LASSO logistic regression models
- `AUC comparison of Stepwise v LASSO Multimodal Model.png` — repeated cross-validation AUC comparison
- `RocVComplexity.jpeg` — CART complexity-parameter tuning curve
- `DecisionTreeForReport.jpeg` — final pruned CART decision-tree visualisation

These outputs are included for portfolio demonstration and project documentation.
